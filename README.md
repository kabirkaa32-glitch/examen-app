# برنامج الحراسة — بناء ملف التثبيت عبر GitHub Actions

يبني GitHub تلقائياً على خادم Windows ملفاً واحداً: **`GuardApp-Setup.exe`** (مثبّت)، ويضعه في صفحة **Releases** ليُحمَّل مباشرة كملف `.exe` وليس ZIP.

## الاستخدام
1. ارفع **محتويات** هذا المجلد إلى جذر المستودع (يفضّل Git أو GitHub Desktop كي يُرفع المجلد المخفي `.github`).
2. **مرة واحدة فقط:** Settings ← Actions ← General ← *Workflow permissions* ← **Read and write permissions** ← Save.
3. تبويب **Actions** ← **Build Windows Installer** ← **Run workflow** (أدخل رقم الإصدار مثل `1.2.0`).
4. بعد 10–15 دقيقة: ادخل تبويب **Releases** (يمين صفحة المستودع) ← اضغط على `GuardApp-Setup.exe` ليبدأ التحميل مباشرة.

رابط التحميل الثابت لآخر إصدار:
`https://github.com/<المستخدم>/<المستودع>/releases/latest/download/GuardApp-Setup.exe`

> إن كان المستودع Private فالتحميل يتطلب تسجيل الدخول إلى GitHub بحساب له صلاحية. للتوزيع على مستخدمين آخرين انسخ الملف وأرسله لهم.

إصدار جديد بالأمر: `git tag v1.2.1 && git push origin v1.2.1`

## ما الذي يعمل دون إنترنت
أثناء البناء يحمّل GitHub مكتبة Excel والخطوط العربية ويدمجها داخل البرنامج؛ بعد التثبيت لا يحتاج المستخدم إلى إنترنت.

## الطباعة
زر «طباعة» في أي صفحة يفتح نافذة بخيارين: **طباعة على الطابعة** (نافذة الطابعات القياسية)، أو **معاينة / حفظ PDF** (يُفتح الملف في قارئ PDF لديك ومنه تطبع أو تحفظ).

## البيانات والسجلات
- قاعدة البيانات SQLite: `%APPDATA%\guard-app\guard.db` (لا تُحذف عند التحديث أو إلغاء التثبيت) + نسخة احتياطية يومية في `backups\`.
- سجل الأخطاء: `%APPDATA%\guard-app\guard.log` — أرسله عند الإبلاغ عن مشكلة.

## ملاحظات
- عند فشل البناء: افتح الخطوة الحمراء في Actions وانسخ آخر 30 سطراً.
- الملف غير موقّع رقمياً، لذا قد يظهر تحذير SmartScreen عند أول تشغيل («مزيد من المعلومات» ← «تشغيل على أي حال»).
- **لا ترفع المفتاح الخاص** لتوقيع الأكواد والتحديثات؛ الموجود في `app.py` هو المفتاح العام فقط.
- بناء محلي: `scripts\build_local.bat`.

## تحديثات الحفظ والقيود والتعديل
- تم إصلاح احتساب الأيام المتتالية في محرك Python (كان يستخدم متغيرًا غير معرّف وقد يؤدي إلى فشل دفعة التوليد).
- تمت إضافة نافذة «عرض جميع القيود» مع مفاتيح تفعيل/تعطيل صغيرة؛ تعارض التوقيت يبقى إلزاميًا.
- إصلاح حفظ إعفاء «كامل الحراسة» في SQLite وإعادته كما هو بعد إغلاق البرنامج وفتحه.
- يحتفظ البرنامج بنسخة SQLite احتياطية يومية قبل أول حفظ في اليوم، مع الاحتفاظ بآخر 14 نسخة في `%APPDATA%/guard-app/backups`.
- أيقونة التبديل باقية في المعاينة؛ تعرض المرشحين من اليوم والتوقيت نفسيهما، مع اشتراط أن تكون حصة الأستاذ الآخر منفردة في ذلك اليوم.


## محرك الحراسة CP-SAT — الإصدار v9

تمت إعادة بناء محرك التوليد حول OR-Tools CP-SAT بدل البحث المحلي العشوائي. لا يستخدم البرنامج محرك JavaScript كبديل صامت عند فشل CP-SAT.

### القيود الصلبة
- جميع المهام يجب أن تُسند؛ لا تُعرض نتيجة جزئية على أنها حل صالح.
- فارق عدد التكليفات بين جميع الأساتذة المؤهلين لا يتجاوز 1.
- فارق أيام الحراسة بين جميع الأساتذة المؤهلين لا يتجاوز 1.
- فارق ساعات الحراسة الأسبوعية لا يتجاوز 4 ساعات افتراضيًا، ويمكن تمرير حد أقل عبر إعدادات المحرك.
- الإعفاءات، وتعارض التوقيت، والحد اليومي، وقاعدة المادة، ومنع الاحتياط المنفرد قيود فعلية.
- الحصة المنفردة محدودة بيوم واحد لكل أستاذ أسبوعيًا، ولا يسمح بتجاوزها إلا عند تفعيل خيار الكسر.
- السماح باحتياطيين مشروط بتفعيل الخيار؛ يجب أن يكونا في يومين مختلفين وأن يكون الأستاذ من الأعلى تكليفًا.
- في وضع «حارس إجباري» تُسند حراسة لكل أستاذ مادة مؤهلة في جلسة مادته، من دون تثبيته على قاعة بعينها قبل أن يحل المحرك التوزيع الكامل.

### البحث والتشخيص
يبحث CP-SAT ضمن مهلة قابلة للضبط، ويعيد تشغيل البحث ببذور مختلفة ويستبعد التوزيعات التي سبق أن وجدها كي يختبر بدائل حقيقية. إذا لم يجد حلاً صالحًا، يوضح أن القيود غير قابلة للتحقيق أو أن مهلة البحث انتهت؛ ولا يرخّي القيود الأساسية ولا يعتمد نتيجة مخالفة.

### التشغيل

```bat
python -m pip install -r requirements.txt -r requirements-build.txt
python app.py
```

### بناء EXE عبر GitHub
ارفع محتويات المجلد إلى المستودع، ثم شغّل سير العمل **Build Windows Installer** من تبويب Actions. سير العمل يثبت OR-Tools، ويفحص استيراد CP-SAT، ويشغّل اختبارات المحرك قبل بناء EXE والمثبّت.

يمكن بناء نسخة محلية على Windows باستخدام `scripts\build_local.bat`.

**تنبيه:** تم فحص الصياغة البرمجية وملفات الواجهة في بيئة التحرير، لكن لم يمكن تشغيل اختبارات CP-SAT هنا لأن مكتبة OR-Tools غير متاحة دون اتصال بالإنترنت. سير عمل GitHub يشغّل الاختبارات بعد تثبيت المكتبة، ويجب اختبار النسخة الناتجة على نسخة احتياطية من قاعدة بيانات المدرسة قبل اعتماد جدول رسمي.
